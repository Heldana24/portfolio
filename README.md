# Personal Portfolio Website — Final Project (Option A)

A modern, responsive, and accessible personal portfolio website built with React, Tailwind CSS, and React Router.

##  Live Demo & Repository
- **Live Deployment Link:** https://heldana24.github.io/PeerConnect
- **GitHub Repository Link:** https://github.com/Heldana24/portfolio

## Overview
This application serves as a professional developer portfolio presenting my background in frontend engineering, component-driven architecture, and computational data workflows. The site features dynamic project routing, an accessible root dark mode toggle, fully responsive multi-device layouts, and a robust stateful contact form.

##  Key Features & Technical Implementation
- **Dynamic Routing:** Individual project detail views rendered dynamically using `react-router-dom` and route parameters (`/projects/:projectId`).
- **Root Dark Mode:** Theme toggling handled dynamically via Tailwind CSS's `dark` class applied to `document.documentElement`.
- **4-State Contact Form:** Form management supporting controlled inputs, validation logic, and handling for `idle`, `submitting`, `success`, and `error` feedback states.
- **Responsive Design:** Fluid Tailwind CSS breakpoints optimized for 375px (mobile), 768px (tablet), and 1280px (desktop) viewports.
